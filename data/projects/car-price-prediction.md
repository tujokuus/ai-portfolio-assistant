# European Vehicle Price Prediction

## Summary

Tuomas Kuusisto's individual project explores European vehicle-listing data and machine-learning models for predicting vehicle prices. The repository describes the project as unfinished and under active development. Tuomas confirms that it is his own work and is not finished.

## Background and timing

The portfolio describes a dataset of more than 118,000 European car listings. The repository README does not provide a project date.

## Tuomas's contribution

Tuomas states that he completed the project individually. The portfolio describes exploratory data analysis, data-quality validation, feature engineering, model comparison, and error analysis. The repository README documents a workflow for those activities but does not provide a separate contribution log.

## Technologies and their uses

The README identifies the project as a Python project through its setup and Python package layout. It describes notebooks for exploratory analysis, baseline modelling, diagnostics, and advanced modelling. The README does not enumerate the project's modelling libraries, so none are attributed here.

## Technical approach

The documented notebook workflow examines data quality, price distributions, country differences, and taxation; compares baseline regression models and tunes candidates; analyzes errors and engineered features; and explores deeper model comparisons, feature selection, and a EUR 200,000 price experiment. The README says the notebooks read `data/raw/cars.csv` and record experiment decisions in `notebooks/experiment_notes.ipynb`.

## Results and current status

The repository explicitly says the project is unfinished and under active development. Its README also cautions that the current validation split was used during model exploration and recommends reserving a new untouched test set before reporting final performance. No performance figures are included here because the repository's own caveat does not support presenting the explored validation results as final test performance.
